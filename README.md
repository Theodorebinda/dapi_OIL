## Congo Energy Logistics

Application vitrine refondue avec Next.js (App Router), Tailwind CSS et TypeScript.

### Prérequis

- Node.js 20+
- Yarn (1.x)

### Installation

```bash
yarn install
```

### Démarrage

```bash
yarn dev
```

L’application est servie sur `http://localhost:3000`.

### Build de production

```bash
yarn build
yarn start
```

### Lint

```bash
yarn lint
```
